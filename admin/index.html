Gestion de la base de données

💾 Base de données serveur

La base de données SQLite est gérée côté serveur. Pour effectuer des opérations de maintenance :

  • Backup : cp server/database/co2m.db server/database/backup-$(date +%Y%m%d).db
  • Restauration : cp server/database/backup-YYYYMMDD.db server/database/co2m.db
  • Réinitialisation : npm run init-db

Consultez DEPLOY.md pour plus d'informations.
